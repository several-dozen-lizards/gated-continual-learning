# Repair of an already learned false admission

Freeze before outcomes. Continue the three Qwen3.5-2B reassessment-plus-replay adapters (seeds 17,29,43), whose one wrong fact per seed was the deliberately corroborated false admission. This is another conditional continuation, not new independent replication. Same model revision, NF4, rank-16 all-linear LoRA, learning rate 0.0002, batch size 4, and 20 replays. Preserve all prior checkpoints and results.

Construct a controlled repair stream: explicitly withdraw both origins that supported the false admission, then add two independent replacement reports with the same supplied reliability histories as before (13 correct, 3 incorrect audits; Beta(1,3) prior; posterior reliability 0.7). Evidence routing reuses the frozen prior implementation and threshold 0.9. Rebuild active evidence after each withdrawal. Withdrawing a source is an externally supplied adjudication, not a learned discovery of deceit. Replacement reports are controlled fictional-world evidence, not proof of general truth verification. The answer key is used by the fixture generator and evaluator, never the repair policy.

Record the original formative claim becoming informational, an uncertain interval with no accepted target, and the corroborated replacement becoming formative. A demoted target leaves the training ledger but remains in provenance receipts. No weight change occurs until the evidence batch finishes. A sham with no repair events retains the old claim. No conversational instruction tells the model it was wrong: train the same factual templates as before.

Each arm starts from exactly the same saved mistaken adapter with a fresh optimizer. Arms: correction only (one fact), corrected ledger replay (twelve facts), and unchanged ledger replay (twelve facts, sham evidence). The last pair exactly matches tokens, padding, examples and optimizer steps; correction-only has a smaller budget and is not an equal-cost replay comparison. Baseline is the unchanged checkpoint evaluated without retrieval. Randomize execution order reproducibly by seed. Evaluate original held-out paraphrases plus four additional predeclared prompt phrasings; these are new prompts over the same subjects, not new fact domains.

Primary outcomes: target correction accuracy, persistence of the old wrong answer, accuracy on the eleven non-target facts, and overall accuracy. Report separately for original and new phrasings, before and after training, with three-seed variation. Correction is behavioral replacement, not proof of erasing every representation. No later stream is included, so long-term stability is untested. Record finite losses/probabilities, prior reload equivalence, fresh reload of corrected-ledger adapter, source/fixture/checkpoint hashes and paired budgets. Record wall time, process CPU time and CUDA event intervals, but do not infer energy/FLOPs or speed savings; event intervals can also include idle gaps. No timing outlier is silently discarded.
